# ⚖️ Vernacular Legal Aid Navigator

An AI-powered multilingual legal assistant for Indian citizens. Describe your legal problem in **English, Hindi, Tamil, or Hinglish** — get applicable laws, the right authority to approach, and documents to carry.

---

## Architecture

```
User Query
    │
    ▼
Agent 1 — Language Normalizer     (Groq LLM)
    │  Detects language, translates to English
    ▼
Agent 2 — Grievance Classifier    (Groq LLM)
    │  Classifies into: labor / land / consumer / family / cyber / police
    ▼
    ├──────────────────────────────────┐
    ▼                                  ▼
Agent 3 — Law Retriever           Agent 4 — Forum Locator
(ChromaDB RAG)                    (Rule-based)
    │                                  │
    └──────────────┬───────────────────┘
                   ▼
Agent 5 — Plain Language Explainer  (Groq LLM)
    │  Converts legal text to simple English
    ▼
Agent 6 — Document Checklist        (Groq LLM + Rules)
    │  Returns required documents
    ▼
Final Report
```

**Orchestration:** LangGraph (Agents 3 & 4 run in parallel)  
**LLM:** Groq — `llama-3.3-70b-versatile`  
**Vector DB:** ChromaDB with `all-MiniLM-L6-v2` embeddings  
**Backend:** FastAPI  
**Frontend:** React + Vite + Tailwind CSS

## Setup & Run

### 1. Prerequisites

- Python 3.12+
- Node.js 18+
- A Groq API key from [console.groq.com](https://console.groq.com)

### 2. Python environment

```bash
cd legal-aid-navigator
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Mac/Linux

pip install -r requirements.txt
```

### 3. Environment variables

Edit `.env`:
```
GROQ_API_KEY=your_groq_api_key_here
```

### 4. Build the knowledge base (run once)

```bash
python build_kb.py
```

This runs all scrapers and indexes everything into ChromaDB.

### 5. Start the FastAPI backend

```bash
uvicorn api:app --reload --port 8000
```

API docs available at: http://localhost:8000/docs

### 6. Start the React frontend

```bash
cd frontend
npm install
npm run dev
```

Open: http://localhost:5173

### Alternative: Streamlit UI

```bash
streamlit run app.py
```

## Supported Languages

| Language | Example |
|----------|---------|
| English | "My landlord is not returning my deposit" |
| Hindi | "मेरा मकान मालिक किराया वापस नहीं दे रहा" |
| Tamil | "என் வீட்டு உரிமையாளர் வைப்புத்தொகை திரும்ப தரவில்லை" |
| Hinglish | "Sir mera landlord deposit wapas nahi de raha" |

## Supported Legal Categories

| Category | Covers |
|----------|--------|
| labor | Wage disputes, wrongful termination, PF, POSH |
| land | Tenancy, deposit, property disputes |
| consumer | Defective goods, e-commerce, refunds |
| family | Maintenance, domestic violence, custody |
| cyber | Online fraud, hacking, identity theft |
| police | FIR, arrest rights, Zero FIR |
